## 프로젝트가 변경되었나요?

**Playlist Canvas**는 **Music Motion Studio**라는 이름으로 변경되었으며, 새로운 저장소에서 개발 및 배포를 이어가고 있습니다.

| 구분 | 안내 |
| --- | --- |
| 이전 프로그램 이름 | Playlist Canvas |
| 새로운 프로그램 이름 | **Music Motion Studio** |
| 이전 저장소 | [Playlist-Canvas](https://github.com/tharu8813/Playlist-Canvas) |
| 현재 공식 저장소 | [Music-Motion-Studio](https://github.com/tharu8813/Music-Motion-Studio) |
| 최신 프로그램 다운로드 | [Music Motion Studio Releases](https://github.com/tharu8813/Music-Motion-Studio/releases/latest) |

기존 `.pvsproj` 및 JSON 프로젝트를 새 프로그램에서 열 수 있으며, 기존 앱 설정과 최근 프로젝트 목록 등도 이어받도록 설계되어 있습니다. 자세한 사항은 [새 공식 저장소의 README](https://github.com/tharu8813/Music-Motion-Studio#readme)를 참고해 주세요.

## 기존 Playlist Canvas 사용자라면

이 저장소는 **리브랜딩 이전 버전에서 1.4.0.0으로 업데이트할 수 있도록 기존 업데이트 경로를 유지하기 위한 호환용 배포 저장소**입니다.

- **이 저장소에서 제공하는 유일한 릴리즈:** [Music Motion Studio 1.4.0.0 (기존 업데이트 호환용)](https://github.com/tharu8813/Playlist-Canvas/releases/tag/1.4.0.0)
- **새 버전 및 이후 업데이트:** [Music Motion Studio 공식 릴리즈](https://github.com/tharu8813/Music-Motion-Studio/releases/latest)

> [!NOTE]
> 이 저장소의 1.4.0.0 릴리즈는 기존 업데이트 경로와 파일명 호환을 위해 `Playlist.Canvas-1.4.0.0-setup.exe`를 제공합니다. 새 공식 저장소의 같은 버전은 `Music.Motion.Studio-1.4.0.0-setup.exe`라는 이름으로 배포되었습니다.
>
> **이 저장소에는 1.4.0.0 이외의 새 릴리즈를 게시하지 않습니다.** 새로운 버전을 직접 다운로드하려면 반드시 [Music Motion Studio 공식 저장소](https://github.com/tharu8813/Music-Motion-Studio)를 이용해 주세요.

## 이 저장소의 운영 안내

- **목적:** 기존 Playlist Canvas 사용자를 위한 1.4.0.0 업데이트 호환성 유지
- **배포 범위:** **1.4.0.0 버전만 제공**
- **개발 및 소스 코드:** 이 저장소에서 제공하지 않으며, [새 공식 저장소](https://github.com/tharu8813/Music-Motion-Studio)에서 관리
- **문의 및 오류 신고:** [새 공식 저장소의 Issues](https://github.com/tharu8813/Music-Motion-Studio/issues) 이용
