# 1.2.0.9 Beta 1 변경 검토

- 기준: GitHub 직전 정식 릴리즈 태그 `1.2.0.8`.
- 검토 시작 HEAD: `dd06e1c`. 기준 이후 47개 커밋(병합 포함), 미커밋 33개 수정 파일과 7개 신규 파일.
- 현재 작업 트리의 AutoMix 편집기, 부분 듣기, 타이포그래피·가사 변경과 관련 테스트를 함께 배포한다.
- 앱·Windows·설치 프로그램 버전: `1.2.0.9`. GitHub 태그: `1.2.0.9-beta.1`, 사전 릴리즈, Latest 지정 안 함.
- 정식 main에 직접 합치지 않고 `codex/release-1.2.0.9-beta.1` 브랜치와 태그로 소스를 게시한다.

## 확인 범위

Git 이력 및 전체 파일 변경 목록을 확인하고, AutoMix의 모델→계획→편집→부분 렌더→미리보기 흐름, Canvas·가사 상태→캡처→최종 렌더 흐름, 프로젝트 패키지 검증, 캐시·스레드 종료, 버전·배포 계약을 검토했다. 모든 변경 코드의 무결점이나 실제 음악 전부의 청감 품질을 보증하는 검토는 아니다.

변경 기능 요약은 같은 폴더의 `1.2.0.9-beta.1.md`에 기록했다. 기존 `automix-editor-handoff.md`와 개선 프롬프트 ZIP은 개발 참고자료이며 일부 구현 전 상태를 설명한다. 릴리즈 기능 상태는 현재 코드와 릴리즈 노트를 따른다.

## 배포 준비 중 수정

- 앱, Windows 버전 리소스, Inno Setup, README 배지와 패키징 예제의 버전을 동기화했다.
- 프로젝트 설정의 AutoMix 설명이 읽기 전용 미리보기 상세창에서 편집하도록 안내하던 문구를 실제 독립 편집기 경로로 수정했다.
- 의존성 변경 없음. Python 3.12.10, 잠금 파일의 33개 패키지 버전 일치, `pip check` 통과.

## 검증 결과

- `python -m compileall -q main.py app tests scripts`: 통과.
- `python scripts/run_tests.py --report build/beta-test-report.json`: 95/95 모듈 통과(255초). 기본 비활성 선택형 테스트는 건너뜀.
- 실제 FFmpeg 9.0으로 `test_automix_ffmpeg_integration`, `test_canvas_pipe`, `test_ffmpeg_streaming_integration`: 3/3 모듈 통과(24초).
- 문서 최종 수정 후 `test_release_contract`: 통과.
- `python -m PyInstaller --noconfirm --clean playlist_canvas.spec`: 통과.
- `python scripts/verify_distribution.py`: 통과. ONNX 모델·라이선스·Python 3.12·NumPy·ONNX Runtime 구성 확인.
- 패키징된 `Playlist Canvas.exe --smoke-test`: 종료 코드 0.
- PyInstaller 경고: 선택형 dask·TBB·일부 숨김 import 부재. soundfile의 libsndfile DLL은 실제 배포 폴더에 존재한다. EXE 쓰기 첫 시도는 권한 오류 후 자동 재시도로 성공했다.
- 새 Windows 계정/VM에서의 설치·제거, 전체 음악 청감, 전체 화면/DPI 조합에 대한 수동 QA는 미실시.
