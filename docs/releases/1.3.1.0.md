# Playlist Canvas 1.3.1.0

1.3.0.0 이후의 변경 사항입니다. 가사 전환과 음악 반응 효과, 시각 타임라인 편집을 추가하고 미리보기 재생과 내보내기 성능을 개선했습니다.

## 가사·자막

- 자막 전환 설정 창을 추가했습니다. 전환 효과, 이동 방향, 속도 곡선, 시간, 이동 거리와 현재 줄의 기준 위치를 조절할 수 있습니다. 기본 이동은 다음 가사가 아래에서 올라와 현재 줄이 되고, 현재 줄은 위로 이동하는 방식입니다.
- 전환 효과는 없음·강조·떠오르기·교차 페이드·슬라이드·확대·순차 이동·바운스를 지원합니다. 순차 이동의 지연은 다음 가사에만 적용합니다.
- 이전·현재·다음 가사의 크기 배율, 불투명도와 블러를 각각 설정할 수 있습니다. 이전과 다음 가사는 현재 줄과의 거리에 따라 흐림과 투명도가 달라지도록 설정할 수 있습니다.
- 곡의 첫 가사 전에는 점이 차례로 밝아지는 임시 인트로 줄을 표시합니다. 긴 무보컬 구간에서도 표시하도록 설정할 수 있으며 점·숨쉬기·물결·막대·링 스타일을 제공합니다.
- 임시 인트로·간주 줄은 가사 순서에 맞춰 추가되고 끝나면 사라집니다. 중앙 기준 위치와 전환 시간을 가사 줄과 공유하도록 수정했습니다.
- 움직임·배치·줄 스타일·인트로를 카테고리별 고급 모드로 설정합니다. 활성화한 카테고리의 값만 기본 속성보다 우선하며, 해당 기본 속성은 비활성화 이유를 표시합니다. 꺼진 카테고리의 고급 값은 적용하지 않으며 적용 버튼은 계속 사용할 수 있습니다.
- 고급 줄 스타일은 크기 배율·불투명도·블러만 설정합니다. 글꼴과 색상은 기본 속성과 줄별 스타일에서 계속 편집할 수 있습니다.
- 줄별 스타일 편집 화면을 개선했습니다. 1번 줄은 기본 스타일을 사용하고, 2~4번 줄을 목록에 먼저 표시하며 나머지는 펼쳐서 편집합니다. 2번 줄 편집 미리보기에는 1번 줄도 함께 표시합니다.
- 가사 설정 미리보기의 줄 수를 늘릴 수 있으며 숨겨진 작은 이스터 에그를 추가했습니다. 자막 전환 옵션에는 설명 툴팁을 추가했습니다.
- 가사가 없는 곡의 `Lyrics are not available for this track.` 안내에는 가사 역할별 블러·불투명도를 적용하지 않습니다.

## 음악 반응·캔버스

- 텍스트 요소와 현재 자막에 음악 반응 효과를 추가했습니다. 저음에 맞춘 크기 변화, 바운스, 늘이기와 기울이기를 선택할 수 있습니다.
- 반응 대역, 강도, 커지는 속도, 감소 속도, 감도, 임계값, 반응 곡선과 시간 오프셋을 조절할 수 있습니다. 자막 반응은 현재 가사에만 적용되며, 미리보기와 내보내기에서 같은 계산을 사용합니다.
- 앨범 커버 기반 주변 배경의 흐림과 움직임 속도를 조절할 수 있도록 개선했습니다.
- 굵은 외곽선·그림자가 있는 도형을 이동할 때 잔상이 남거나 효과가 잘리는 문제를 수정했습니다. 정렬 기준은 도형 본체를 유지합니다. 새 도형 선택에서는 선을 제외하고, 기존 프로젝트의 선 도형은 보존합니다.

## 시각 타임라인·편집 도구

- 하단 타임라인에 곡과 요소를 블록으로 표시하는 시각 편집 화면을 추가했습니다. 드래그 이동, 길이 조절, 스냅, 확대·축소, 뒤 구간을 함께 미는 편집과 실행 취소를 지원합니다.
- 타임라인에서 지정한 위치를 메인 미리보기로 재생할 수 있습니다. 기존 수치 편집도 사용할 수 있습니다.
- MP3 메타데이터 편집기를 추가했습니다. 제목·아티스트·앨범·앨범 아티스트·연도·장르·트랙·디스크·BPM·설명과 커버 이미지를 원본 MP3의 ID3 태그에 저장할 수 있습니다.
- LRC 생성기에서 선택한 플레이리스트 곡의 가사를 불러오고 편집 결과를 해당 곡에 직접 적용합니다. 동일 파일이 여러 번 등록된 경우 선택한 곡을 우선하며, 저장하거나 적용할 대상이 없는 결과를 그대로 닫지 않도록 안내합니다.
- 누락된 외부 가사 파일을 해제해도 프로젝트 내부에 저장된 가사는 보존합니다.
- 비활성화된 콤보박스·입력값·텍스트의 색상과 아이콘을 바꿔 사용 가능한 설정과 쉽게 구분하도록 개선했습니다.

## AutoMix

- 음량·저음·보컬 겹침과 다음 곡의 시작 부분 손실을 비교하는 전환 후보 탐색을 추가했습니다. 곡 구조와 보컬·박자 정보를 활용해 전환 길이와 착지 위치를 선택합니다.
- 저음과 중음의 전환 시점을 독립적으로 계산하고, 수동으로 지정한 전환을 우선합니다. 분석 정보가 불확실한 경우 기존 분석과 안전한 페이드로 대체합니다.
- YAMNet을 이용한 장르·분위기 분석을 추가했습니다. 모델과 라이선스를 설치본에 포함하며 로컬에서 분석합니다. 신뢰도와 분석 범위를 확인한 결과만 전환 선택에 반영합니다.
- 수동 전환에 Beat Roll과 Lowpass Out을 추가했습니다. 반복할 박자 길이와 마지막 저역 통과 필터 주파수를 설정할 수 있습니다.
- 전환 상세 정보에 음량 저하·저음 충돌·보컬 가림·시작 부분 손실·착지 오차 및 장르·분위기 분석을 표시합니다.
- 박자 정렬 오차 측정, 템포 램프의 시작 속도 처리와 긴 구간의 시간 눈금을 개선했습니다. AutoMix 작업 공간 복원과 템포 맞춤 도구 접근도 수정했습니다.

## 미리보기·안정성·성능

- 메인 재생 미리보기의 작업 스레드 수명 관리를 수정해 재생 중 멈추거나 종료되는 문제를 개선했습니다.
- 끝까지 재생한 뒤 다시 재생하면 처음부터 시작하도록 수정했습니다. 같은 오디오를 다시 사용할 때 불필요한 소스 로딩 신호를 기다리던 문제를 고쳐 재재생 시 소리가 나오지 않는 현상을 해결했습니다.
- 이전 형식의 `subtitle_advanced_enabled` 값이 저장된 프로젝트를 현재 카테고리별 설정으로 변환해 열 수 있도록 수정했습니다.
- 음악 반응 체크박스를 켤 때 비어 있는 콜백을 호출하던 오류를 수정했습니다.
- 가사 블러를 단색 알파 처리로 최적화했습니다. 1280×720, 7개 가사 큐를 사용하는 로컬 비교에서 프레임 캡처 시간이 12.544ms에서 9.223ms로 약 26.5% 줄었으며 흰색 가사 픽셀은 동일했습니다. 실제 결과는 프로젝트와 하드웨어에 따라 달라집니다.
- 영상 프레임 간격의 작은 흔들림 때문에 정상 프레임을 버리던 문제를 완화했습니다. NV12 프레임의 동일 크기 복사와 평면 준비 비용도 줄였습니다.
- 내보내기 시작 시 음악 반응용 오디오 분석을 작업 스레드로 옮겨 UI 응답성을 개선했습니다. 성능 측정 도구와 기록도 추가했습니다.
- 한국어·영어 도움말과 스크린샷을 새 가사 전환·줄 스타일·음악 반응·타임라인·MP3 편집 기능에 맞춰 갱신했습니다.
- AI 프로젝트 빌더 기능을 삭제했습니다. 기존 디자인 프리셋은 계속 사용할 수 있습니다.
- 앱·Windows 실행 파일·설치 프로그램의 버전을 1.3.1.0으로 맞췄습니다. 배포 리소스 검사를 강화하고 개발 환경의 Python 사용자 지정 모듈이 설치본에 들어가지 않도록 제외했습니다.

## 설치

첨부된 **`Playlist.Canvas-1.3.1.0-setup.exe`**를 내려받아 실행하세요. 기존 설치본과 같은 앱 ID를 사용하며 `SHA256SUMS.txt`로 배포 파일의 해시를 확인할 수 있습니다.

FFmpeg는 설치본에 포함되지 않습니다. **도구 → 설정 → FFmpeg → FFmpeg 자동 다운로드 및 설치**에서 설치할 수 있습니다. 크로스페이드와 AutoMix에는 FFmpeg가 필요합니다.

## 배포 검증

- Python 3.12.10과 고정 의존성 33개 일치 확인, Python 소스 컴파일, 전체 117개 테스트 모듈 통과. 총 1,569개 테스트 중 선택적 모델·GPU·장시간 실행 등 환경 조건이 필요한 18개는 건너뛰었습니다.
- 실제 FFmpeg의 AutoMix·영상 스트리밍 통합 테스트 통과. 실제 오디오 PCM을 검사해 원본·믹스 미리보기를 끝까지 재생한 뒤 반복 재생해도 오디오가 생성되는 것을 확인했습니다.
- 새 PyInstaller 배포본의 필수 리소스, 4,938개 파일 SHA-256 무결성, 새 기능 모듈 포함 및 개발 환경 사용자 지정 모듈 제외 확인.
- 실행 파일·설치 프로그램 버전 1.3.1.0 확인, 배포 실행 파일의 시작·정상 종료 검사 통과, Inno Setup 설치 프로그램 빌드 완료.

세부 결과는 첨부한 테스트·FFmpeg·빌드 보고서에서 확인할 수 있습니다. 새 Windows 계정 또는 가상 머신에서의 설치·제거, 물리 오디오 장치의 청감 검증은 자동 검사에 포함하지 않았습니다.
