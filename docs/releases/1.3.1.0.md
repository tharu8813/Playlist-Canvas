# Playlist Canvas 1.3.1.0 변경 내역

이 문서는 다음 릴리즈를 위한 소스 변경 내역입니다. 전체 테스트와 최종 설치본 검증은 작업 중단으로 완료되지 않았습니다.

- MP3 메타데이터 편집기와 가사 줄별 스타일 편집 화면을 개선했습니다.
- 자막 이동 방향, 전환 효과, 다음 가사의 순차 이동과 이전·현재·다음 가사의 크기·불투명도·블러를 설정할 수 있습니다. 거리별 블러와 임시 인트로·간주 줄도 지원합니다.
- 자막 고급 모드를 카테고리별로 적용합니다. 활성화한 카테고리의 기본 속성만 잠기며, 줄별 색상과 글꼴은 계속 편집할 수 있습니다.
- 텍스트와 현재 자막에 음악 반응 효과를 추가했습니다. 반응 대역, 강도, 상승·감소 속도 등을 조절할 수 있습니다.
- 하단 타임라인에 곡과 요소를 직접 이동하고 길이를 조절하는 시각 편집 화면을 추가했습니다.
- 재생 미리보기의 작업 스레드 종료와 오디오 재시작 처리를 개선했습니다. 끝에서 재생을 누르면 처음부터 시작합니다.
- 가사가 없는 곡의 안내 문구에 자막 전환용 블러가 적용되지 않도록 수정했습니다. 이전 형식의 자막 고급 설정이 있는 프로젝트도 불러올 수 있습니다.
- 가사 블러와 영상 프레임 복사 비용을 줄이고, 내보내기 오디오 분석을 작업 스레드에서 처리합니다.
- AutoMix의 음악 분석과 전환 후보 선택, 수동 전환 편집을 개선했습니다.
- 비활성 설정의 표시를 개선하고 한국어·영어 도움말과 화면 안내를 갱신했습니다.
- AI 프로젝트 빌더를 삭제했습니다. 디자인 프리셋은 유지합니다.
- 앱, Windows 실행 파일 및 설치 프로그램의 버전을 1.3.1.0으로 맞추고 새 모델·도움말·UI 리소스의 배포 검사를 보완했습니다.
