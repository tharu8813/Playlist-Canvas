# Playlist Canvas 1.3.1.1

1.3.1.0 이후의 변경 사항입니다. 영상·오디오·자막 내보내기를 확대하고, 소리가 들리지 않는 상황을 안내하며, 프로그램 시작 화면을 개선했습니다.

## 영상·오디오 내보내기

- 영상 출력 형식에 MOV·MKV를 추가했습니다. 기존 MP4도 계속 사용할 수 있습니다.
- 플레이리스트의 오디오만 MP3·M4A·WAV·FLAC·OGG로 저장할 수 있습니다. WAV·FLAC는 무손실 출력이며, 곡 전환·AutoMix·음량 처리를 반영합니다.
- 내보내기 항목, 파일 형식, 파일 이름과 저장 폴더를 따로 선택하도록 설정 창을 개선했습니다. 사용할 수 없는 파일 이름과 기존 파일 덮어쓰기를 확인합니다.
- 오디오 출력에서는 화면·GPU 인코딩 준비를 생략하고 오디오에 맞는 진행 상태, 저장 공간 사용량과 완료 안내를 표시합니다.
- 인코딩 실패나 취소 시 기존 결과 파일을 보존합니다. 오디오 출력의 스트림과 재생 길이를 확인합니다.

## 믹싱 타임라인에 맞춘 자막

- 플레이리스트 가사를 LRC·SRT 파일로 내보낼 수 있습니다. 곡 자르기, 재생 속도, 템포 변화와 가사 시간 보정을 실제 오디오 타임라인에 반영합니다.
- 두 곡의 가사가 겹치면 나가는 곡을 윗줄, 들어오는 곡을 아랫줄에 표시합니다. 겹침이 끝나면 한 곡의 가사만 표시합니다.
- 가사가 없는 구간과 마지막 가사 이후에는 이전 가사를 지웁니다. 여러 줄 LRC 가사의 저장·불러오기 처리를 개선했습니다.
- 곡 전환 없는 자막은 FFmpeg 없이 내보낼 수 있습니다. 믹싱 자막은 실제 믹스 준비 결과로 시간을 맞춥니다.
- 설명문·CSV를 만드는 메뉴를 **타임라인 내보내기**로 바꾸고, 믹싱 후 곡 시작 시간을 저장한다는 안내를 추가했습니다.

## 오디오 출력 안내

- 메인 미리보기, 전체 미리보기, AutoMix 편집기, LRC 생성기와 곡 상세 화면에 오디오 상태 안내를 추가했습니다.
- 블루투스 출력에서는 소리가 화면보다 늦게 들릴 수 있음을 안내합니다. 정확한 가사·전환 타이밍 편집에는 유선 이어폰·헤드폰 또는 스피커를 권장합니다.
- 출력 장치 없음·연결 해제, 앱 음소거·볼륨 0, Windows 출력 음소거·볼륨 0, Windows 볼륨 믹서의 앱 음소거와 재생 오류를 안내합니다.
- 장치와 볼륨 변경에 맞춰 안내를 갱신합니다. 장치 상태를 읽을 수 없는 경우 음소거로 단정하지 않으며, 시스템 볼륨을 자동으로 변경하지 않습니다.

## 프로그램 시작 화면

- 시작 화면에 진행 막대와 백분율을 추가했습니다. 프로그램·분석 환경·편집 도구·작업 공간을 준비하는 실제 단계에 맞춰 진행률을 갱신합니다.
- 어두운 스튜디오 색상과 민트색 강조, 선명한 앱 아이콘, 정돈된 글자와 여백으로 디자인을 개선했습니다.
- 한국어·영어 상태 문구와 버전을 표시하며, 편집 화면을 열면 시작 화면이 닫힙니다.
