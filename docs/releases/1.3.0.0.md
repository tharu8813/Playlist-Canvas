# Playlist Canvas 1.3.0.0

**1.2.0.8 이후의 전체 업데이트를 통합한 정식 릴리즈입니다.** 1.2.0.9 Beta 1과 1.2.0.10의 모든 변경 사항에 이후 AutoMix·곡별 오디오·도움말·UI 개선을 더했습니다. 이전 두 릴리즈는 이 통합 릴리즈로 대체됩니다.

## AutoMix 전환 편집과 미리듣기

- 플레이리스트와 도구 메뉴에서 독립 AutoMix 편집기를 열어 곡 사이 전환을 직접 편집합니다. 실제 파형, 박자·마디 그리드, 큐·겹침 구간, 대역별 전환 레인을 표시합니다.
- 단순/고급 모드, 확대·이동, 박자·마디 스냅, 키보드 미세 이동, 실행 취소/다시 실행, 전환 복사·붙여넣기, 자동 전환 복귀를 지원합니다.
- 전환 스타일·길이·큐·템포·보컬 교대와 Custom EQ 대역별 타이밍을 조정할 수 있습니다. 전환 프리셋을 이름으로 저장하고, 내 편집과 자동 전환을 A/B 비교(B 키)할 수 있습니다.
- 편집한 전환만 백그라운드에서 준비해 재생·탐색·반복·음량 조절을 제공합니다. 인접 전환의 필터 처리 상태를 반영해 미리듣기의 일관성을 높였습니다.
- **새 전환 방식:** Echo Out, Tape Stop, 다운비트 컷, Filter Sweep을 추가했습니다. 에코 지연·감쇠·저역 차단, 테이프 진입과 키 이동 등 효과별 설정을 제공합니다.
- **템포·키 연결:** 최대 16% 템포 브리지와 16마디 램프, 최대 두 반음의 키 이동을 지원합니다. 음색·곡 흐름과 후보별 프레이즈 정렬, 키 충돌, 에너지 흐름을 전환 선택에 반영합니다.
- **직접 지정한 값 보존:** 수동 전환의 스타일과 길이를 존중하고, 곡 끝 핸들이 되돌아가거나 전환 구간이 뜻하지 않게 줄어드는 문제를 수정했습니다. 에코 여운은 곡 파일 끝 이후까지 지정 구간에 맞게 이어집니다.
- **선택 중심 편집 화면:** 중앙 타임라인에서 전환, A 큐, B 시작, 템포 변화, 대역을 선택하면 해당 속성을 표시합니다. 선택 영역과 행 라벨을 더 명확하게 강조합니다.
- 드래그 중 값·이동량·스냅 지점을 표시하고 Esc로 취소할 수 있습니다. 한 번의 드래그는 하나의 실행 취소 단계가 됩니다. Shift로 스냅을 일시 반전하고 박자 또는 0.01초 단위로 미세 이동합니다.
- 자동 계획과 다른 값, 개별 초기화, 플래너의 보정 이유를 표시합니다. 큐와 길이의 ‘값 유지’를 저장하며, 프리셋·붙여넣기는 해당 전환의 큐와 유지 값을 보존합니다.
- 미리듣기의 준비 중·최신·변경 후 갱신 필요·실패 상태를 구분합니다. 창 최대화, 템포 변화 시작점 드래그, 작업 영역 기억·초기화를 지원하고 마커 라벨 겹침을 줄였습니다.
- 곡 정보의 분석 탭에서 곡별 분석 결과와 단계별 진행 상황을 확인합니다. 미리보기의 전환 상세는 실제 재생 계획을 보여 주는 별도 읽기 전용 창으로 제공합니다.

## 곡별 음량과 EQ

- 곡 정보에 **오디오 탭**을 추가했습니다. 곡별 음량과 5밴드 EQ를 조절하고 처리된 미리듣기로 확인할 수 있습니다.
- 곡별 오디오 설정은 일반·크로스페이드·AutoMix 내보내기의 믹싱 전에 적용됩니다.
- 전체 믹스에는 공통 게인을 사용하는 **-14 LUFS 목표 정책**을 적용합니다. 피크가 높으면 오버샘플링 리미터를 사용하고 과도한 증폭을 제한합니다.

## 가사·디자인·애니메이션

- 가사 줄 전환의 밝기·크기·흐림을 연속적인 움직임으로 개선했습니다. 줄이 바뀔 때 깜빡임과 튐을 줄이고 이전 줄에 가우시안 블러를 적용합니다. 가사 공백에서는 강조가 부드럽게 풀립니다.
- 긴 가사는 영역에 맞게 축소하며, 스크롤 중 글자 테두리가 이전 위치에 남거나 흐린 줄의 테두리만 선명하게 남는 문제를 수정했습니다.
- 텍스트 자간·줄 간격·기울임꼴·대소문자, 글자 모양 그림자·글로우·그라데이션, 그라데이션 회전, 가사 정렬·현재 줄 크기·강조 색을 추가했습니다.
- 요소 마스크 8종(원·알약·아치·다이아몬드·삼각형·육각형·별·하트), 진행 막대 핸들(기본값·없음·원·막대), 현재 재생 카드의 상단 문구 변경·숨김·정렬을 지원합니다.
- 원형 비주얼라이저를 추가했습니다. 원 안쪽에 맞춘 원형 앨범 커버를 배치하고 그룹으로 묶을 수 있습니다.
- 등장·퇴장 효과에 줌 아웃, 통통 튀기, 떠오르기, 떨어지기, 스핀, 흔들며 등장, 뒤집기를 추가해 총 16종을 제공합니다.
- 반복 모션 7종(둥실 떠다니기·숨쉬기·맥박·흔들림·회전·떠돌기·출렁임)을 추가했습니다. 캔버스·미리보기·내보내기가 같은 애니메이션 계산을 사용합니다.
- 디자인 프리셋 7종(노래방·플로우·시네마 자막·리릭 포스터·네온 나이트·파스텔 드림·바이닐)을 추가하고 기존 11종을 개선했습니다. 기존 프리셋 중 6종에도 가사를 추가했습니다.
- AutoMix·크로스페이드 겹침 중간에 앨범 커버와 화면 요소가 자연스럽게 다음 곡으로 전환됩니다. 등장·퇴장 길이를 믹스 길이에 맞추고 전환 중에도 비주얼라이저·레벨 미터를 계속 갱신합니다.

## 미리보기·편집 성능과 화면

- AutoMix 미리보기 믹스를 여러 구간으로 병렬 준비하고 곡별 레벨 분석도 병렬 처리해 대기 시간을 줄였습니다.
- GPU 프레임 텍스처를 매 프레임 재할당하던 문제를 수정했습니다. 비트 분석 모델을 재사용·미리 준비하고 백그라운드 분석·렌더링 우선순위를 조정해 재생 중 멈춤을 줄였습니다.
- 플레이리스트·타임라인·콘텐츠 목록은 표시 내용이 바뀔 때 필요한 부분을 갱신합니다. 앨범 커버를 썸네일 크기로 디코딩하고 밝기·대비, 배경 이미지 처리와 박자 그리드 계산을 최적화했습니다.
- 미리보기 준비 중 로딩 안내를 표시합니다. 완료된 믹스 준비 작업이 상태 표시줄에 계속 남는 문제를 수정했습니다.
- 설정·프로젝트 설정·미리보기의 공간과 배치를 개선하고 작은 화면에서는 설정 탭을 스크롤할 수 있게 했습니다.
- 미리보기 타임라인에 곡별 블록·곡명·재생한 구간·전환 구간·재생 위치를 표시합니다. 곡 목록은 커버·제목·세부 정보·길이를 구분하고 정보가 없으면 파일명을 표시합니다.
- 플레이리스트의 메타데이터·길이·가사/BPM 배지와 도구 버튼을 다듬고 미리보기 이전/다음 곡 버튼에 표준 아이콘을 적용했습니다.
- 상태 표시줄의 작업 목록에 고정 버튼, 긴 이름 생략 표시와 더 다양한 작업 진행 표시를 추가했습니다.

## 내보내기와 안정성

- Windows에서 Canvas 프레임을 파이프로 최종 FFmpeg 인코더에 직접 전달해 중간 영상과 임시 디스크 사용을 줄였습니다. 대체 내보내기 경로를 유지하고 중간 영상 품질도 개선했습니다.
- 반투명 레이어 순서, 진행률, 파이프 종료·실패·취소 처리를 보강하고 사용이 끝난 오디오 중간 파일과 오래된 임시 폴더를 정리합니다.
- 음악 추가를 FFmpeg 설정보다 먼저 안내하며 FFmpeg 안내를 닫으면 내보내기를 취소합니다. 가져온 곡 수 표시도 수정했습니다.
- 프로젝트 패키지의 잘못된 자산 경로·중복 자산을 거부하고 이전 프로젝트 데이터 변환과 검증을 분리했습니다.
- Qt 작업 스레드 종료, 목록 갱신, 미리보기를 닫을 때의 편집기 처리와 설정 창 참조 정리를 개선했습니다.
- AutoMix 메모리 캐시 상한, 동시 파일 해시 계산 공유, 오래된 디스크 캐시 정리를 추가했습니다. 특수 문자가 포함된 곡 ID의 수동 전환과 겹침 없는 컷 전환을 보존합니다.
- 비정상 종료 위치를 `%LOCALAPPDATA%\PlaylistCanvas\logs\native-crash.log`에 기록합니다. 반복되는 영상 필터 오류 로그를 줄였습니다.
- 내보내기·AutoMix·프로젝트·UI 회귀 테스트, 스트리밍 스트레스 검증, 테스트 프로세스·임시 경로 격리를 보강했습니다.

## 프로젝트·도움말·유지 관리

- M3U/M3U8에서 로컬 음악을 가져오고 현재 플레이리스트를 M3U8로 내보낼 수 있습니다.
- 새 프로젝트 설정, 첫 실행 안내, 복구·저장·내보내기 안내를 개선했습니다. 앱과 AutoMix 편집기 첫 실행에 그림 안내를 제공합니다.
- **새 사용자 가이드:** 창별 탭과 한국어·영어 56개 주제, 태그 필터, 전체 검색·검색어 강조, 주석이 있는 스크린샷과 관련 주제 링크를 제공합니다.
- **F1 상황별 도움말:** 현재 창·패널·설정·편집 단계에 맞는 도움말을 엽니다. 가사·AutoMix 편집기의 단축키 요약은 Shift+F1로 확인합니다.
- **설정 → 유지 관리:** 설치 파일 SHA-256 무결성 검사, 검증된 최신 설치본으로 강제 재설치, 환경설정·캐시 초기화 및 재시작을 지원합니다. 초기화 시 프로젝트·프리셋·언어팩·관리형 FFmpeg를 보존합니다.
- 한국어 Qt 표준 대화상자 번역과 외부 언어팩 크기 제한을 개선했습니다. 시간 표시·언어 판별·분석 캐시·속성 편집·글자 효과의 공통 처리를 정리했습니다.

## 설치

첨부된 **`Playlist.Canvas-1.3.0.0-setup.exe`**를 내려받아 실행하세요. 기존 설치본(1.2.0.9 베타·1.2.0.10 포함)을 같은 앱 ID로 업데이트합니다. `SHA256SUMS.txt`로 설치 파일의 해시를 확인할 수 있습니다.

FFmpeg는 설치본에 포함되지 않습니다. **도구 → 설정 → FFmpeg → FFmpeg 자동 다운로드 및 설치**에서 검증된 배포본을 설치하세요. 크로스페이드와 AutoMix에는 FFmpeg가 필요합니다.

AutoMix 결과는 음악의 리듬·보컬 구성에 따라 달라질 수 있습니다. 전환 미리듣기와 최종 내보내기는 전체 믹스의 최종 음량 처리에 따라 차이가 날 수 있습니다.

## 배포 검증

- Python 소스 컴파일, 고정 의존성 33개 일치 확인, 전체 회귀 테스트 104개 모듈 통과.
- 실제 FFmpeg를 사용하는 AutoMix·영상 스트리밍 통합 테스트 2개 모듈 통과.
- 새 Windows 계정/가상 머신에서의 설치·제거와 다양한 음악에 대한 수동 청감 검증은 이번 자동 검증에 포함하지 않았습니다.
