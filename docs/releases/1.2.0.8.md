# Playlist Canvas 1.2.0.8

AutoMix의 박자·보컬 분석과 곡 전환을 개선하고, 미리보기와 프로젝트 불러오기를 더 편하게 만든 업데이트입니다. 기존 PyTorch 분석기를 가벼운 ONNX 모델로 교체했습니다.

## 주요 변경 사항

- **가벼운 오프라인 AutoMix 분석:** Beat This!의 박자·다운비트 분석과 Open-Unmix의 보컬 감지를 ONNX Runtime으로 실행합니다. 모델과 Sonara 곡 구조 분석기를 설치본에 포함하며 추가 모델 다운로드가 필요하지 않습니다. PyTorch와 Demucs는 설치본에서 제외했습니다.
- **음악에 맞춘 자동 전환:** 박자 격자와 마디 시작점, 전환 주변의 실제 템포를 반영합니다. 나가는 곡의 끝부분 템포를 다음 곡에 맞춰 점진적으로 바꾸거나 곡의 여운 위로 다음 곡을 시작하며, 전환 스타일은 자동으로 결정됩니다. 이전 프로젝트의 수동 스타일 설정도 자동 스타일로 적용됩니다.
- **보컬을 고려한 믹스:** 반주 인트로·아웃트로를 우선 활용하고, 다음 곡의 노래가 소절 중간부터 시작되는 것을 방지합니다. 두 곡이 끝과 시작에서 모두 노래하면 짧은 전환을 사용해 겹치는 시간을 줄입니다. 분석하지 않은 구간을 반주로 오인하지 않도록 보컬 분석 범위를 구분합니다.
- **즉시 열리는 Preview:** 오디오 준비를 기다리는 별도 창 없이 미리보기 창이 열립니다. 믹스 준비와 분석 진행 상황은 상태 표시줄에서 확인할 수 있습니다. 최종 미리보기 오디오는 내보내기와 같은 음량 처리 후 무손실 FLAC으로 준비합니다.
- **상세 진행 상황:** 상태 표시줄에 여러 작업의 진행률과 AutoMix 분석·내보내기 단계가 표시됩니다. 마우스를 올리거나 클릭하면 세부 현황을 확인할 수 있습니다.
- **프로젝트 불러오기 개선:** 프로젝트의 내장 미디어를 백그라운드에서 불러오며, 오래 걸리는 작업의 진행 상황 확인과 취소를 지원합니다.

## 수정 사항

- 같은 음악 파일을 이동하거나 프로젝트를 다시 열 때 AutoMix 분석을 반복하던 문제를 파일 내용 기반 캐시로 개선했습니다. 새 분석 방식 적용을 위해 기존 캐시는 처음 한 번 다시 분석될 수 있습니다.
- AAC/M4A 파일의 곡 구조 분석 시간이 실제보다 길게 계산되던 문제를 FFmpeg 디코딩 경로로 수정했습니다.
- 미리보기 재생이 분석보다 앞서 진행되어도 같은 곡의 같은 위치를 유지하며 새 믹스로 전환하도록 개선하고, 부분 믹스 실패 후 불필요한 반복 처리를 방지했습니다.
- AutoMix와 크로스페이드의 중간 오디오를 부동소수점 PCM으로 처리하여 음량 정규화 이전의 클리핑을 방지합니다.
- 일정한 음량 조절만 필요한 오디오는 빠른 측정·게인 처리 경로를 사용하고, 동적 처리가 필요한 경우 기존 2단계 음량 정규화를 유지합니다.
- 사용을 마친 믹스 중간 파일을 일찍 정리하여 임시 디스크 사용을 줄였습니다.
- AutoMix 상세 정보에 마지막 보컬 종료·첫 보컬 시작 위치를 추가하고, 이어서 재생을 선택한 이유를 표시합니다.
- 작업 스레드 종료 처리와 컨트롤러의 상태 관리를 정리하고, 속성 편집기와 회귀 테스트를 기능별로 분리했습니다.
- Windows 배포 의존성에 Sonara를 명시하고, 배포본의 ONNX 모델·라이선스·런타임 검증을 보강했습니다.

## 설치

`Playlist.Canvas-1.2.0.8-setup.exe`를 내려받아 실행하세요. 기존 설치본이 있으면 같은 위치에 업데이트됩니다.

FFmpeg는 프로그램에 포함되지 않으며 **도구 → 설정 → FFmpeg → FFmpeg 자동 다운로드 및 설치**에서 검증된 배포본을 설치할 수 있습니다. 크로스페이드와 AutoMix에는 FFmpeg가 필요합니다.

## 알려진 제한

- AutoMix는 베타 기능입니다. 두 곡이 전환 구간에서 모두 노래하면 짧은 보컬 겹침이 남을 수 있으며, 조용한 인트로나 복잡한 리듬에서는 전환이 자연스럽지 않을 수 있습니다.
- 보컬 분석은 곡의 앞뒤 구간을 대상으로 합니다. 분석하지 않은 중간 구간은 보컬 유무를 알 수 없는 구간으로 처리합니다.
- 곡 끝부분의 점진적인 템포 변경은 가사 등 일부 화면 요소의 곡 내부 시간 계산에 아직 반영되지 않아, 전환 직전 표시 타이밍에 차이가 생길 수 있습니다.
- 코드 서명되지 않은 설치 파일에는 Windows SmartScreen 안내가 표시될 수 있습니다.
