# Playlist Canvas 1.2.0.9 Beta 1

1.2.0.8 이후의 변경사항을 포함한 Windows 베타 릴리즈입니다. GitHub 사전 릴리즈이므로 정식 자동 업데이트에는 노출되지 않습니다. 앱과 Windows 파일 버전은 기존 네 자리 규칙에 따라 1.2.0.9입니다.

## AutoMix 편집과 미리듣기

- 플레이리스트에서 독립 AutoMix 편집기를 열어 곡 사이 전환을 직접 조정할 수 있습니다.
- 두 곡의 실제 파형, 박자·마디 그리드, 큐와 겹침 구간, 대역별 전환 레인을 표시합니다. 확대·이동, 박자 스냅, 키보드 미세 이동을 지원합니다.
- 단순/고급 모드, 전환 스타일·길이·큐·템포·보컬 교대·Custom EQ 대역 타이밍, 실행 취소/다시 실행, 설정 복사/붙여넣기와 자동 전환 복귀를 지원합니다.
- 편집한 전환의 듣기 구간을 백그라운드에서 준비하며 재생·탐색·반복·볼륨 조절을 제공합니다. 전환 편집마다 전체 플레이리스트를 다시 렌더하지 않습니다.
- 미리보기의 전환 상세는 실제 재생 계획을 보여 주는 읽기 전용 창으로 분리했습니다. 임시 계획, 준비 진행 상황과 갱신 실패를 구분합니다.
- 곡 정보의 분석 탭에서 곡별 분석 결과와 단계별 진행 상황을 확인할 수 있습니다.

## 화면과 자막

- AutoMix·크로스페이드의 겹침 중간에 앨범 커버와 화면 요소가 다음 곡으로 자연스럽게 전환됩니다. 비주얼라이저와 레벨 미터가 전환 중에도 계속 움직입니다.
- 화면 요소의 등장·퇴장 애니메이션을 믹스 길이에 맞출 수 있습니다.
- 텍스트 자간, 기울임꼴, 대소문자 표시, 글자 모양 그림자와 글자 그라데이션, 그라데이션 회전 설정을 추가했습니다.
- 현재 가사의 강조 크기·색상과 가사 사이 공백의 강조 해제를 개선하고 미리보기와 내보내기에 함께 반영했습니다.
- 진행 막대의 핸들을 기본값·없음·원·막대로 선택할 수 있습니다.

## 내보내기와 음량

- Windows에서 Canvas 프레임을 파이프로 최종 FFmpeg 인코더에 직접 전달하여 중간 영상 준비와 임시 디스크 사용을 줄였습니다. 대체 내보내기 경로는 유지합니다.
- 반투명 레이어 순서, 진행률, 파이프 종료·실패·취소 처리를 보강했습니다.
- 전체 믹스에 공통 게인을 적용하는 -14 LUFS 목표 정책으로 변경했습니다. 피크가 높으면 오버샘플링 리미터를 적용하고 과도한 증폭을 제한합니다.
- 사용을 마친 오디오 중간 파일과 오래된 임시 폴더를 정리합니다.

## 프로젝트와 사용성

- M3U/M3U8 플레이리스트의 로컬 음악 가져오기와 M3U8 내보내기를 지원합니다.
- 새 프로젝트 설정, 시작 안내, 복구·저장·내보내기 안내를 개선했습니다. 작은 화면에서 설정 창을 스크롤할 수 있습니다.
- 한국어 UI에서 Qt 표준 대화상자 번역을 적용하고 외부 언어팩 크기 제한을 보완했습니다.
- 프로젝트 패키지의 잘못된 자산 경로와 중복 자산을 거부하고 이전 프로젝트 데이터의 마이그레이션을 분리했습니다.
- Qt 작업 스레드 종료와 목록 갱신 안정성을 개선했습니다. AutoMix 메모리 캐시 상한, 동시 해시 계산 공유, 오래된 디스크 캐시 정리를 추가했습니다.
- 내보내기·AutoMix·프로젝트·UI 회귀 테스트와 테스트 프로세스 격리를 보강했습니다.

## 설치와 제한

- 첨부된 `Playlist.Canvas-1.2.0.9-beta.1-setup.exe`를 실행하세요. 기존 설치본과 같은 앱 ID를 사용하므로 기존 버전을 교체합니다.
- FFmpeg는 설치본에 포함되지 않습니다. 설정의 FFmpeg 자동 다운로드 기능으로 설치할 수 있습니다.
- AutoMix는 베타 기능입니다. 복잡한 리듬이나 보컬 겹침 구간에서는 전환이 자연스럽지 않을 수 있습니다.
- 전환 듣기는 동일 계획과 DSP를 재사용하지만, 인접 전환의 필터 상태·최종 전체 믹스 음량 처리에 따라 최종 내보내기와 차이가 날 수 있습니다. 템포 램프가 있는 나가는 곡은 오디오 처리 상태를 맞추기 위해 곡 앞부분도 준비합니다.
- 새 Windows 계정/가상 머신에서의 설치·제거 및 다양한 실제 음악에 대한 수동 청감 검증은 이번 자동 검증에 포함하지 않았습니다.
