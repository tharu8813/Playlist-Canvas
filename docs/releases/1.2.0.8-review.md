# 1.2.0.8 릴리스 검토 기록

## 비교 범위

- 기준: GitHub 최신 공개 릴리스 `1.2.0.7` (2026-09-23).
- 기존 변경: 릴리스 이후 커밋 14개 및 작업 트리의 수정 파일 15개·신규 테스트 1개.
- 위 변경을 모두 포함하고, 버전·문서·배포 의존성·검증 절차를 이번 릴리스에 맞게 보완했다.
- 사용자용 변경 설명과 알려진 제한: [릴리스 노트](1.2.0.8.md).

## 검증

- Python 3.12.10, 잠금 파일의 설치 버전 대조: 일치. `pip check`: 통과.
- `python -m compileall -q main.py app tests scripts`: 통과.
- `python scripts/run_tests.py`: 82/82 모듈 통과. 선택형 외부 도구 검사는 별도로 아래에서 수행했다.
- FFmpeg 9.0으로 `tests.test_automix_ffmpeg_integration` 및 `tests.test_ffmpeg_streaming_integration`: 21개 테스트 통과.
- PyInstaller 클린 빌드: 성공. Python 3.12 런타임, ONNX 모델 2개와 라이선스, ONNX Runtime 네이티브 모듈 포함 확인.
- 배포 실행 파일 `--smoke-test`: 분리된 LOCALAPPDATA에서 종료 코드 0, 약 3초.
- 기존 개발 앱의 실행 표식으로 비정상 종료 안내가 나타나는 환경 간섭을 확인했다. CI 실행 검증도 독립 데이터 폴더를 사용하도록 변경했다.
- 실행 파일 버전: 1.2.0.8. PyTorch는 배포 폴더에서 제외됨.
- `git diff --check`: 통과. 변경 파일의 일반적인 토큰·개인 키 패턴 검사: 검출 없음.
- 새로운 Windows 계정/VM에서 설치·제거 및 사람의 실제 음악 청감 검증은 이번 점검에서 수행하지 않았다.

## 배포 준비에서 보완한 사항

- 앱, Windows EXE, Inno Setup, README, 패키징 가이드의 버전을 1.2.0.8로 통일.
- CI의 잠금 의존성에 누락된 `sonara==0.3.6` 추가. 기존 빌드 환경과 같은 버전이다.
- 배포 폴더 검증에 ONNX 모델·라이선스·네이티브 런타임·Python DLL 추가.
- README의 AutoMix 설명을 실제 미리보기·내보내기 기능과 일치시킴.
- 이전 릴리스의 한국어 구성(주요 변경 사항 / 수정 사항 / 설치)을 참고해 릴리스 노트 작성.
