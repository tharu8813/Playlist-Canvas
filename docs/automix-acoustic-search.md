# AutoMix 음향 기반 전환 선택

AutoMix는 전환 길이를 먼저 고르고 효과를 나중에 붙이는 대신, 큐·길이·저음/보컬 인계를 함께 비교한다.
Basic과 Beat This!/ONNX가 이미 디코딩한 PCM에서 1초 단위 RMS, 저음 비중, 밝기, 타격감을 측정한다.
기존 timbre 추출기를 재사용하며 추가 모델 다운로드나 의존성은 필요 없다. 분석기 버전 증가로 이전 캐시는 다시 분석한다.

- 1·2·3·4·6·8·12·16마디 중 길이와 실제 비트 안정성에 맞는 후보를 비교한다.
- 비트를 맞출 수 있어도 원래 템포를 유지하는 인계를 함께 비교한다. 첫 다운비트 앞의 보컬을
  버리거나 과도한 템포 변화를 줄 때에는 자연스러운 인계가 우선할 수 있다.
- 첫 보컬, 측정된 섹션 경계, 지속적인 타격감 상승에 전환의 **끝**을 맞추는 후보도 만든다.
  추가 후보는 앞의 보컬을 생략하지 않는다. 나가는 곡의 마지막 소리와 소스 범위 보호는 유지한다.
- 실제 구간의 음량 공백/돌출, 저음 충돌, 가려지는 보컬, 동시 보컬, 조성 충돌을 비용으로 비교한다.
  다음 곡의 드럼이 전환 직후 들어오는 경우에는 그 구간도 음량·저음 기준에 포함한다.
- 저음과 보컬 인계를 각각 조절한다. 선택한 qsin EQ 구간은 기존 `band_windows`로 저장하므로
  미리보기·내보내기·수동 편집기의 전환 그림이 같은 계획을 사용한다.
- Sonara가 없어도 측정한 에너지/타격감으로 기존 프레이즈 컷·에코·자연스러운 엔딩 판단을 사용할 수 있다.
  절/후렴/드롭 등의 의미 라벨은 만들어 내지 않는다.
- 템포가 달라도 1·2·3·4·6·8초 인계와 보컬 보호 EQ를 비교한다. 에코/테이프 스톱은 실제 타격감이
  확인되고 마지막 가사를 끊지 않을 때만 자동 선택한다. 자연스러운 엔딩을 에코로 대체하지 않는다.
- 보컬이 미측정이면 긴 중역 오버레이를 피하고, 조성 충돌은 좁은 중역 인계로 보호한다.
  곡/구간의 측정값이 없으면 기존 보수적 선택으로 처리한다. 수동 큐·길이·스타일과 잠금은 우선한다.

비용은 학습된 청취 품질 확률이 아니다. 1초 음향 특징으로 렌더러의 페이드 전력을 예측하는 근사치이며,
보컬 분리는 EQ만으로 완벽하지 않다. 리듬 분석과 함께 안전한 후보를 고르는 데 사용하고,
사람의 청취를 대체하거나 전문 DJ 수준을 보증하는 수치로 표시하지 않는다.

검증: `python -m unittest tests.test_automix_intelligence`
실제 FFmpeg 검증은 `PLAYLIST_CANVAS_TEST_FFMPEG`에 실행 파일 경로를 지정한다.
로컬 음원 비교: `python tools/automix_listening_report.py OUT SONG1 SONG2 --ffmpeg PATH --compare`.
`comparison.json`과 `compare/`의 before/after FLAC은 같은 분석의 이전 선택과 개선된 선택을 비교한다.
음량/저음 수치와 `ratings.csv` 청취 평점을 함께 확인한다. 생성 음원·보고서는 커밋하지 않는다.
