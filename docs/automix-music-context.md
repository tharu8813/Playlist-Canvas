# AutoMix 장르·분위기 분석

AutoMix는 포함된 YAMNet ONNX 모델로 음원에서 음악 스타일과 분위기를 분석한다.
네트워크 업로드, TensorFlow 설치, 실행 중 모델 다운로드는 필요하지 않다.
기존 Basic/Beat This!/ONNX 분석 경로가 같은 PCM 신호를 재사용한다.

- 앞 60초, 뒤 60초, 중간 16초를 분석한다. 겹치는 범위는 합친다.
- 8초 구간마다 장르·분위기 점수를 저장한다. 곡 전체의 라벨로 미분석 구간을 추측하지 않는다.
- 실제 전환 구간의 80% 이상이 분석되었을 때만 길이로 가중 평균한다.
- 0.35 미만 점수는 믹싱에 영향을 주지 않는다. 여러 라벨을 유지한다.
- 장르·분위기는 분석 캐시에 저장한다. 분석 버전 증가로 이전 캐시는 다시 분석한다.

댄스/전자음악과 신나는 분위기가 양쪽에서 확인되면 긴 비트 블렌드에 가점을 준다.
힙합 또는 잔잔함과 강렬함이 서로 대비되는 전환은 짧은 후보를 우선한다.
클래식/재즈/포크/앰비언트 또는 슬프고 다정한 분위기는 부드러운 전환을 사용하며,
높은 점수(0.55 이상)에서 자동 템포 변경을 3% 이내로 제한한다.
이런 전환에서는 자동 컷/에코/테이프 스톱을 대신해 기존 페이드를 유지한다.
보컬과 조성 충돌 보호, 실제 비트 안정성, 소스 범위 제한은 장르보다 우선한다.
사용자가 지정한 수동 전환은 계속 우선한다.

전환 상세 창은 나가는/들어오는 구간의 장르·분위기와 모델 점수를 표시한다.
점수는 분류 정확도나 보정된 확률이 아니다. YAMNet은 범용 AudioSet 모델이므로
K-pop, 발라드 등의 세부 장르를 모두 분류하지 않는다. 낮은 점수, 미분석 구간,
누락/고장난 모델은 기존 리듬·보컬·에너지 기반 믹싱으로 처리한다.

출처: [YAMNet](https://www.tensorflow.org/hub/tutorials/yamnet),
[ONNX 변환](https://huggingface.co/audiomagic/yamnet-onnx).
모델/라벨의 라이선스·고정 버전·체크섬은 `YAMNET_NOTICE.md`에 있다.
